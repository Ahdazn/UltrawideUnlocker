# UltrawideUnlocker
LSPosed Module to unlock 0.5x / 0.6x ultrawide camera on selected camera apps.

## Features:
- Modifies `CONTROL_ZOOM_RATIO_RANGE` (minimum zoom 0.5x)
- Exposes hidden auxiliary Camera IDs (IDs 2, 3, 4)
- Bypasses vendor aux package whitelist (`vendor.camera.aux.packagelist`)
- Automatic GitHub Actions build to compile APK
